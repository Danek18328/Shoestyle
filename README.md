# 👟 SHOESTYLE

### Plataforma web para una tienda de calzado

SHOESTYLE es una plataforma web desarrollada para presentar, administrar y gestionar una tienda de calzado mediante una interfaz moderna y un backend desarrollado en PHP y MySQL.

El proyecto integra catálogo de productos, usuarios, compras, facturación, administración, contacto, reseñas y generación de reportes.

# ✨ Características

## 🏠 Experiencia de usuario

- Página principal de SHOESTYLE
- Diseño responsive
- Navegación entre secciones
- Galería fotográfica
- Presentación de la empresa
- Página de servicios
- Redes sociales
- Formulario de contacto

---

## 👟 Productos

- Catálogo dinámico
- Consulta de productos desde MySQL
- Información de productos
- Gestión de inventario
- Administración de productos
- Creación de productos
- Edición de productos
- Eliminación de productos

---

## 👤 Usuarios

- Registro de usuarios
- Inicio de sesión
- Sistema de roles
- Acceso diferenciado para usuarios y administradores
- Gestión de información de clientes

---

## 🛒 Compras

- Selección de productos
- Carrito mediante sesiones PHP
- Registro de compras
- Cálculo del total
- Registro de ventas
- Generación de factura
- Impresión de factura

---

## 🧾 Facturación y reportes

El sistema registra las operaciones realizadas y permite generar documentos a partir de la información almacenada en la base de datos.

Incluye:

- Facturas
- Reportes de productos
- Reportes de ventas
- Reportes de empleados
- Exportación a PDF mediante FPDF

---

## ⭐ Reseñas

Los usuarios pueden dejar una valoración sobre SHOESTYLE.

Cada reseña incluye:

- Nombre
- Comentario
- Calificación
- Registro en MySQL

---

## 📩 Contacto

El formulario de contacto permite registrar:

- Nombre completo
- Correo electrónico
- Teléfono
- Mensaje

La información es almacenada en la base de datos para su posterior administración.

---

## 📊 Administración

SHOESTYLE incorpora un panel administrativo para gestionar información interna de la plataforma.

### Funciones

- Gestión de productos
- Gestión de empleados
- Consulta de ventas
- Actualización de información
- Eliminación de registros
- Exportación de información
- Consulta de estadísticas

---

## 👁️ Sistema de visitas

El proyecto incorpora un contador de visitas conectado a una base de datos independiente.

Permite registrar y consultar el número de visitas recibidas por la plataforma.
